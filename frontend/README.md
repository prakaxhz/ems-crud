# Employee Management System - Frontend

Single Page Application (SPA) frontend for the Employee Management System built with **React 18** and **Vite**. Features decoupled API integrations through custom hooks, pure backend-driven validation handling, responsive design, Excel import modal, and direct Excel/CSV exports.

---

## 🛠 Tech Stack & Architecture

- **Build Tool & Framework**: Vite + React 18
- **Routing**: React Router DOM (v7)
- **HTTP Client**: Axios with centralized request/response interceptors
- **Icons**: React Icons (`react-icons/fi`, `react-icons/lu`)
- **Key Architectural Decisions**:
  - **Decoupled API Integrations**: UI components contain **zero direct API calls**. Every backend interaction is delegated to custom hooks (`useAuth`, `useEmployees`, `useEmployeeForm`, `useEmployeeImport`).
  - **Backend Validation Hook**: Instead of validating in the client, backend Laravel validation errors are parsed and mapped to field errors dynamically using `useBackendErrors`.
  - **Auto-managed Authorization**: Axios interceptor automatically injects `Authorization: Bearer <token>` and handles 401 unauthenticated redirects.
  - **Readonly Employee ID**: In both Add and Edit modes, Employee ID is strictly displayed in `readOnly` state as generated by backend logic.

## 🚀 Setup & Installation

### 1. Clone & Navigate
```bash
cd "d:\interview\creative bees\myapp"
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Configuration
Create a `.env` file in the `myapp/` root (or configure via `src/services/apiClient.js` default `http://localhost:8000/api`):
```ini
VITE_API_BASE_URL=http://localhost:8000/api
```

### 4. Run Development Server
```bash
npm run dev
```
The application will launch at `http://localhost:5173`.

### 5. Build for Production
```bash
npm run build
```
The compiled assets will be placed in the `dist/` directory.

## ✨ Features

- **Authentication**: Sanctum token-based login, persistent session via `localStorage`, and auto-redirect on unauthorized responses.
- **Employee CRUD**:
  - Auto-generated, read-only employee IDs (e.g., `EMP000001`).
  - View details modal.
  - Update employee modal.
  - Delete employee with confirmation dialog.
- **Search, Filter & Sort**:
  - Instant search across name, email, phone, and qualification.
  - Qualification dropdown filter.
  - Date of Birth range filters.
  - Server-side sorting on table column headers with pagination.
- **Import & Export**:
  - Import employees via `.xlsx` / `.csv` drag-and-drop modal with error reporting.
  - Export filtered lists directly to Excel (`.xlsx`) or CSV (`.csv`) via authorized blob downloads.
- **Error Handling**: Form validation errors returned by Laravel are mapped to their respective form inputs dynamically via `useBackendErrors`.
